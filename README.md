# Little Petals — Kids Clothing Storefront

Cream & white floral e-commerce frontend for kids clothing (girls & boys, ages 1 month–15 years).

## Features

- **Home** — branded hero, girls/boys entry, wear-type links, featured products
- **Shop** — filter by gender, age band, daily/night/party wear, and price range; sort by price or name
- **Product detail** — size (age band), quantity, add to cart
- **Cart** — update quantities, remove items, checkout demo

## Run

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## Stack

React + TypeScript + Vite + React Router
